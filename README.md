## 🚀 Featured Project

### 💊 My Online Pharmacy

**My Online Pharmacy** is a C-based pharmacy management system created as a practical programming project.

The project focuses on implementing programming fundamentals such as functions, file handling, searching, menus, and basic management operations.

### Key Features

* 👤 Customer interface
* 🔐 Administrator interface
* 💊 Medicine management
* 🔎 Medicine search
* 🛒 Shopping/cart functionality
* 📄 File-based data storage
* 📋 Menu-driven interface

**Built with:** `C`
